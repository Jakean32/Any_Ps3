Any_Ps3 — third-party licenses and components
==============================================

Any_Ps3 itself is MIT licensed. This Windows build links the following
permissively-licensed components; full license texts are included below.

Shipped in this archive:
------------------------
1) Any_Ps3 — MIT (see LICENSE in the source archive)
2) Dear ImGui v1.91.9b (ocornut/imgui) — MIT — statically linked UI toolkit
3) stb_image.h (nothings/stb) — public domain / MIT-0 — PNG decoding for
   game cover images (ICON0.PNG)
4) MinGW-w64 runtime — statically linked into Any_Ps3 under its
   permissive runtime exemption (GCC runtime library exception applies
   because the program is GPL-compatible-licensed... Any_Ps3 is MIT, and the
   GCC exception explicitly permits static linking of libgcc/libstdc++
   into any license). Binutils/ld are build-time tools only (not shipped).

Not shipped / not linked:
-------------------------
- No Sony firmware, no decryption keys, no Sony SDK headers, no game content.
- zlib1.dll is NOT part of this package (it was only built locally to verify
  the artifact under Wine; zlib is anyway not embedded in the exe).
