## v0.6.0 — 2026-10-25 — "Android app overhaul: working log download, readable UI, real icon"

- Fixed (user report, Android 13): "app crashes when pressing export logs" — the whole export path is rebuilt crash-proof: every entry catches `Throwable` (the old `catch (Exception)` could not stop `Error`-class failures such as `UnsatisfiedLinkError`), and the primary export no longer touches the share sheet at all. Honest note: the exact device-side exception was not reproducible in this sandbox (no device/emulator); the new in-app crash report screen will capture it verbatim if anything still fails.
- Added: "Save log report to Downloads" — MediaStore insert into `Download/Any_Ps3/` (Android 10+; works with no permissions and no share sheet; the user gets a real file). Android 9 fallback: app-specific documents dir. Share sheet remains as a secondary path with grant flags on chooser + inner intent.
- Added: full-screen in-app log viewer (level filter All/Info/Warn/Error, text search, selectable text, copy-all, save, share, auto-scroll) — logs are now readable WITHOUT any export.
- Added: in-app crash report screen (selectable full stack trace + Copy / Save to Downloads / Share / Delete; closing keeps it for the next start) — replaces the old platform dialog.
- Added: real storage stats (library vs. cache bytes) + "Delete old exported log files" in app settings (real action, only touches files this app created).
- Added: honest "About" panel (version, engine status, what works / in development).
- Redesigned: whole Android UI — explicit high-contrast dark palette (every text has a checked foreground color; body text ~15:1, secondary >= 4.5:1 on #0B0E13 — no black-on-black anywhere), minimum font size 12sp (log viewer 12sp mono with 17sp line height; old log panel was 10sp), game cards with status chips (Ready / Encrypted-key-needed / decryption-active), one primary action per card, extended "Import game" FAB, search with clear button, dismissible feedback banner for every action, remove-confirmation dialog, empty state with brand logo, log peek bar at the bottom of the library.
- Redesigned: real adaptive launcher icon — gold "3" with glow over a night-blue gradient and the brand's mountain silhouette; monochrome layer for Android 13 themed icons; legacy circle PNGs for all densities; 512px store icon (`download/Any_Ps3-icon-512.png`). Generated by `scripts/gen_android_icons.py` (PIL, no third-party assets).
- Fixed (latent Compose bug): per-game SettingsScreen wrote snapshot state DURING composition (`pad = pad + …` in the render loop) — illegal in Compose, can loop recomposition forever; now a local `mutableStateMapOf` written only from input callbacks and saved on Save.
- Fixed: UI state loss on rotation — `AppUiState` moved to the Application (library, log, banners, crash report survive activity re-creation); manifest configChanges extended (screenLayout/smallestScreenSize/keyboard/density).
- Updated: VERSION 0.6.0, versionCode 4. This is an Android-focused release: the Windows host is functionally unchanged since v0.5.0 (its binary remains `Any_Ps3-0.5.0-Windows-x64.zip`; the Windows exe's version string stays 0.5.0 until the next functional Windows build).
- Verification (honest): Gradle assembleDebug green; aapt2 badging 0.6.0 / versionCode 4 / arm64-v8a / target 35; apksigner verify OK; new classes (Diagnostics, LogViewerScreen, CrashReportScreen, saveToDownloads/MediaStore) confirmed inside the shipped dex; icon reviewed via VLM (contrast on dark wallpaper 8/10). NOT verified: on-device run (no Android hardware here) — the user's install is the test; if anything still crashes, the new crash screen captures the exact stack trace.

## v0.5.0 — 2026-10-24 — "Real executables: module HLE bring-up pipeline"

- Added: PS3 module facts in the ELF loader — ET_SCE_EXEC(0xFE00)/ET_SCE_PPURELEXEC(0xFFA4) acceptance, ALL phdrs kept, TLS info phdr (0x60000000), sys_proc_prx_param phdr (0x60000002, magic 0x1b434cec), sceModuleInfo VA via first PT_LOAD p_paddr (adopted for SCE types, or when p_paddr lands inside the first segment's file image).
- Added: guest-side sceModuleInfo parse (libstub window) + libstub walker (0x2C entries; module name, NID table, entry-slot table, var/TLS warnings, attribute-0x2000 use-addresses) — `ReadModuleImports`.
- Added: cellOS module HLE (`hle/modules.*`): registry of 19 modules / 9040 public NIDs (PSL1GHT MIT stub tables vendored under tools/reference/psl1ght + rpcs3 NID→name facts for sysPrxForUser/libc; generator `gen_module_tables.py` committed), guest trampolines (lis r11,0x1000/ori/sc/blr) + 8-byte descriptors, LV2-style slot patching (`LinkImportsToHle`), honest MISSING handler (CELL_ENOSYS + one-line log + bring-up summary), sys_prx registry (load/start/stop/unload/get-id-by-name).
- Added: real HLE implementations — sysPrxForUser (threads/lwmutex[cooperative retry]/spinlock/prx/exit-callbacks/memory/syscall-reusing wrappers), strings+memory+printf family over guest RAM, bump heap (_sys_malloc etc.), _sys_qsort with a REAL guest comparator (synchronous re-entry into the interpreter via a reserved return trampoline), cellSysutil params/callbacks, cellSysmodule, cellGcmSys init-level, cellPad honest-no-backend, libc/libstdcxx basics.
- Added: LV2 sys_prx syscalls (480/481/482/483/494/495/496, verified numbers) + named ENOSYS logging via generated `syscall_names.h` (449 names from the verified table; `gen_syscall_names.py`).
- Added: Boot v2 — OPD entry (pc + r2=TOC), TLS block + r13, argv/envp/frame stack layout, import linking with bring-up notes, `MISSING` summary in the boot log; exit callbacks executed for real after the main thread exits.
- Added: encrypted-retail-EBOOT fallback — user-supplied DECRYPTED executable (their own dump/tools) via per-game settings (Windows file dialog; Android SAF fd + validated app-private copy `eboot.dec.elf`); GameSettings.eboot_path persisted.
- Added: tests — `tests/fixtures/module.s` (real binutils PPC64: OPD entry, PowerOpen import stub, sysPrxForUser NID import, unknown-NID ENOSYS) + 4 module tests (end-to-end boot, proc-param fallback, demo direct-entry unchanged, prx registry honesty). Suite: 66/66.
- Fixed (major): interpreter hardwired `gpr[0]=0` every step — dropped ALL legitimate writes to r0 (PowerOpen import stubs use r0 as scratch); r0 is now a real register (rA=0 addressing still means zero base; X-form rB is always a real index).
- Fixed: trampoline `lis` encoding was addi (0x396…) instead of addis (0x3D6…) — r11 became 0x1000|idx, hit LV2 as syscall 4097 (caught by the module fixture + binutils verification).
- Fixed: ParsePs3ModuleInfo double-offset (guest_mem already included the VA).
- Fixed: ppu fixtures generator — toolchain discovery (in-repo tools/ppc64tools, LD_LIBRARY_PATH handling), sources moved to tests/fixtures/, carry-over of archived fixture bytes (fp/vmx/sync/threads) when sources are absent.
- Docs: RESUME.md (multi-session state, next-10-tasks), this changelog; README/PHASE_REPORTS/TEST_PLAN updated for v0.5.0.
